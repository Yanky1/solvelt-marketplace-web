# Solvelt marketplace website

The buyer website of the Solvelt marketplace. It uses React + TypeScript with React Router v7 in framework mode, renders on the server for SEO, and follows the Solvelt Figma styling.

- The backend is [solvelt-marketplace-api](https://github.com/Yanky1/solvelt-marketplace-api). Workstreams and briefs live in that repo's docs/.
- The standing rules for Claude sessions are in [CLAUDE.md](CLAUDE.md).
